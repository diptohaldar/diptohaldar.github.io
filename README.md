# Dipto Kumar Haldar — Version 2 Research Website



## Run
Open `index.html`, or run:
```bash
python -m http.server 8000
```

## GitHub Pages
Create a repository, upload these files to `main`, then:
**Settings → Pages → Deploy from a branch → main → / (root)**.

## Customize
- Replace the Google Scholar placeholder with the exact profile URL.
- Add a profile photo in `assets/` if desired.
- Add future papers/projects in `index.html`.
